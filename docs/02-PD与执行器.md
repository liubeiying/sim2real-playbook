# PD 增益与执行器建模

## 症状

- 动作幅度**整体偏大或偏小**（不是局部问题）
- 机器人"软绵绵"或者"过硬"
- 仿真里力气刚好，真机上使不上劲

## 查什么

| 项 | 检查内容 |
|---|---|
| 刚度 Kp / 阻尼 Kd | 数值本身 |
| **单位与量纲** | 两个引擎是否同一套单位 |
| 控制类型 | 位置控制 / 力矩控制，两者 PD 含义不同 |
| 力矩上限 | 是否被截断 |
| 摩擦与阻尼模型 | 关节摩擦建模差异 |

## 单位问题是重灾区

同一个"Kp = 100"，在不同框架里可能意味着完全不同的物理量。
**不要只看数字，要确认它乘在什么量上。**

## 执行器建模差异

- 力矩上限设置不同 → 真机"使不上劲"
- 关节摩擦未建模 → 仿真里过于顺滑
- 电机动态（一阶滞后）忽略 → 高速运动时相位偏差

1. 给一个阶跃目标位，记录两个引擎的响应曲线
2. 对比上升时间、超调、稳态误差
