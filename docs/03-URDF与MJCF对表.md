# URDF / MJCF 对表清单

两个仿真行为不一致时，把参数逐项对表。退化是查出来的，不是猜出来的。

## 对表清单

| 检查项 | 不一致的后果 | 结果 |
|---|---|---|
| 关节限位 | 仿真能做、真机做不了的动作 | 待补 |
| 速度上限 | 轨迹能规划但执行跟不上 | 待补 |
| 连杆惯量与质心 | 力矩与接触响应偏掉 | 待补 |
| 碰撞模型 / 连杆尺寸 | 穿透、假接触、抓不稳 | 待补 |
| 阻尼 | 动作衰减快慢不同 | 待补 |
| 初始位置 | 起始姿态就不一样 | 待补 |
| 执行器建模 | 力矩上限与响应差异 | 待补 |
| mimic 从动关节 | 自由度数与真机指令数不一致 | 待补 |

## mimic 关节这个坑（灵巧手必踩）

- URDF 里常用 `<mimic>` 定义从动关节，比如四指 distal 跟随 proximal
- **MJCF 没有这个概念**
- 后果：仿真自由度不等于真机可下发指令数，动作在真机上对不上

处理三步：

1. 明确真机实际可主动控制的自由度
2. 仿真侧补全执行器定义
3. 锁定从动关节，保证与真机指令一致
